Rules I wrote

Rule 1

body {
    font-family: comic sans ms, sans-serif;
    line-height: 1.6;
    margin: 0;
    padding: 0;
    background-color: #ffe5f1;
    align-items: left;
    display: flex;
    flex-direction: column;
}

Without it, my page would have no color or decoration.

Rule 2

h1, h2, h3, h4, h5, h6 {
    color: #ff69b4;
    border-bottom: 2px solid #69c8ff;
    text-shadow: 4px 4px 4px #62c0ff;
    font-weight: bold;
}

It changes all my heading words on every page.

Rule 3

a {
    color: #c20469;
    text-decoration: underline;
    text-decoration-color: #c20469;
    text-decoration-style: dotted;
    text-decoration-thickness: 2px;
    text-decoration-color: #bd085c;

}

This rule makes my links colored and underlined.
